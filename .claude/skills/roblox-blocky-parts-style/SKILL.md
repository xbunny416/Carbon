# Roblox blocky-parts style

## The look in one sentence
Real-world objects simplified into boxes, wedges and cylinders: recognizable proportions, almost no curves, muted colors, a little surface texture from built-in materials, and soft, hazy daylight.

The goal is the *feel*, not a specific model. Any subject (car, house, tree, bench, truck, shop, lamp post) should be reinterpreted this way.

## Core principles
1. **Silhouette first.** Get the big masses right (body, cabin, roof, trunk) before any detail. A model should read clearly from 30+ studs away.
2. **Primitives only.** Use `Part` (Block, Cylinder, Ball sparingly), `WedgePart` and `CornerWedgePart`. No MeshParts, no Unions unless asked.
3. **Fake bevels with wedges.** Chamfer hoods, roof edges, windshields and wall corners with wedges instead of curves.
4. **Medium detail.** Include details that define the object (window frames, trim strips, bumpers, chimneys, door lines, headlights). Skip tiny ones (screws, handles under 0.3 studs, text).
5. **Layering for depth.** Windows are slightly inset or sit inside a frame. Trim is a thin part (0.1–0.2 studs) offset from the surface. Walls sit on a slightly wider base or foundation.
6. **Real-world scale.** 1 stud ≈ 0.28 m. A character is ~5 studs tall. A car ~14 L × 6 W × 5 H; a door ~4 × 7; a house floor ~10–12 studs tall.

## Palette
Muted, slightly desaturated, earthy. Avoid pure white, pure black and saturated primaries.

| Use | Color3.fromRGB |
|---|---|
| Off-white body / plaster | 205, 200, 190 |
| Warm plaster | 215, 205, 180 |
| Roof brown | 120, 95, 80 |
| Roof dark | 85, 70, 65 |
| Trim / foundation grey | 160, 160, 165 |
| Dark details (tires, grilles) | 35, 38, 45 |
| Glass | 150, 175, 185 (Transparency 0.4–0.6) |
| Accent (lights, small signs) | 200, 90, 40 / 220, 200, 120 |
| Foliage | 70, 140, 90 / 95, 160, 100 |
| Trunk | 110, 85, 65 |
| Ground / dirt | 140, 115, 85 |

Vary colors slightly (±5–10 per channel) across repeated objects so a scene doesn't look copy-pasted.

## Materials
- `SmoothPlastic`: vehicles, painted metal, trim, glass
- `Plaster` or `Concrete`: walls
- `RoofShingles`, `ClayRoofTiles` or `Slate`: roofs
- `Brick`: chimneys, bases
- `Wood` / `WoodPlanks`: shutters, fences, doors
- `Plastic` or `LeafyGrass`: foliage blocks
- `Ground` / `Sand` / `Pebble`: ground plates
- Never use `Neon` except for a deliberately glowing light.

## Shape recipes (adapt, don't copy)
- **Gable roof:** two WedgePart halves meeting at the ridge, overhanging the walls by ~1 stud on all sides. Add a thin ridge cap.
- **Vehicle:** lower body block → wedge-chamfered hood and trunk → narrower cabin with wedge windshields → transparent window parts → cylinder wheels (rotated 90°) slightly tucked into the body → thin bumper blocks and small light blocks.
- **Tree (stylized):** thin block trunk + 2–5 stacked or offset cube clusters, or a tall tapering stack for cypress shapes.
- **Windows:** frame parts around a recessed glass part. Optional shutters as thin wood blocks.
- **Chimney:** brick block poking through the roof with a slightly wider cap.

## Building with code
Generate models with a Luau script the user can run in the Studio command bar or as a Script.

- Use a helper like:
  ```lua
  local function part(props)
      local p = Instance.new(props.Class or "Part")
      p.Anchored = true
      p.TopSurface = Enum.SurfaceType.Smooth
      p.BottomSurface = Enum.SurfaceType.Smooth
      p.Material = props.Material or Enum.Material.SmoothPlastic
      p.Color = props.Color or Color3.fromRGB(200, 200, 200)
      p.Size = props.Size
      p.CFrame = props.CFrame
      p.Transparency = props.Transparency or 0
      p.Name = props.Name or "Part"
      p.Parent = props.Parent
      return p
  end
  ```
- Position everything **relative to an origin CFrame** so the model can be placed, rotated and cloned anywhere.
- Group into a `Model` with a sensible `PrimaryPart` and clear part names (`Body`, `Roof_L`, `Wheel_FL`, `Window_Front`).
- Wrap each object in a function with parameters, for example `buildHouse(origin, {floors = 2, width = 16, roofColor = ...})`, so variants are easy.
- **WedgePart orientation is easy to get wrong.** Build one test wedge first, check which way the slope faces, then rotate (often 90° or 180° around Y) to match.
- Wheels: `Shape = Enum.PartType.Cylinder`. A cylinder's axis is its X axis, so rotate it to face the side.

## Part budgets
- Small prop: 5–20 parts
- Vehicle: 25–60 parts
- House: 40–120 parts
- Mention in the output if a scene would exceed ~5,000 parts, and suggest reusing templates.

## Scenes and variation
For multiple objects (village, street, forest), build 2–4 template variants and place them with a script. Add random rotation in 90° steps, small offsets, color jitter and optional features (chimney yes/no, shutters yes/no). Use a seed (`Random.new(seed)`) so layouts are reproducible.

## Lighting suggestion (optional, include for scenes)
Soft, hazy daylight: `Lighting.Technology = Future` or `ShadowMap`, a light blue `Atmosphere` with some haze, gentle shadows, and slightly warm ambient light.

## Avoid
- Smooth curves, high part counts on tiny details, floating or overlapping clutter
- Saturated "toy" colors, neon, rainbow palettes
- Copying any specific branded vehicle or building exactly
- Unanchored parts in static models

## Output format
1. One line describing the interpretation (what the object is and its key shapes).
2. A single complete Luau script, ready to paste into the Studio command bar.
3. A short note on parameters the user can tweak.
